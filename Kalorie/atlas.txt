┌────────────────────────────────────────────────────────────────────────┐
│  ①  CREATE A CLUSTER                                                    │
└────────────────────────────────────────────────────────────────────────┘

    • Click  "Build a Database" / "Create"
    • Choose the FREE  M0  tier
    • Pick any provider / region near you
    • Click  Create


┌────────────────────────────────────────────────────────────────────────┐
│  ②  CREATE A DATABASE USER                                              │
└────────────────────────────────────────────────────────────────────────┘

    • Sidebar →  Database Access  →  Add New Database User
    • Authentication =  Password
    • Set a username + password   (use "Autogenerate Secure Password")
    • ⚠  COPY & SAVE THE PASSWORD  — you can't see it again
    • Role =  "Read and write to any database"  →  Add User


┌────────────────────────────────────────────────────────────────────────┐
│  ③  ALLOW NETWORK ACCESS                                                │
└────────────────────────────────────────────────────────────────────────┘

    • Sidebar →  Network Access  →  Add IP Address
    • Click  "Allow Access from Anywhere"   ( 0.0.0.0/0 )
    • Confirm
        ↳ Vercel uses rotating IPs, so this is the correct choice.


┌────────────────────────────────────────────────────────────────────────┐
│  ④  GET THE CONNECTION STRING                                           │
└────────────────────────────────────────────────────────────────────────┘

    • Sidebar →  Database  →  click  "Connect"  on your cluster
    • Choose  "Drivers"  (Node.js)
    • Copy the string — it looks like:

        mongodb+srv://<db_username>:<db_password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority


┌────────────────────────────────────────────────────────────────────────┐
│  ⑤  FIX UP THE STRING  (important)                                      │
└────────────────────────────────────────────────────────────────────────┘

    • Replace  <db_username>  and  <db_password>  with the user from ②
    • Insert the database name  calorie-tracker  right before the  ?

        mongodb+srv://myuser:mypassword@cluster0.xxxxx.mongodb.net/calorie-tracker?retryWrites=true&w=majority

    • If the password has special chars ( @ : / # ? ) → URL-encode them
      ( e.g.  @ → %40 ).  Easiest: use an autogenerated alphanumeric password.

    ➜  This final string is your  MONGO_URI


┌────────────────────────────────────────────────────────────────────────┐
│  ⑥  WHERE TO PUT THE MONGO_URI                                          │
└────────────────────────────────────────────────────────────────────────┘

    LIVE SITE  →  VERCEL   (the one that matters for deployment)
    ───────────────────────────────────────────────────────────
    • Vercel → project → Settings → Environment Variables → Add New
    • Key:    MONGO_URI
    • Value:  the full string from ⑤
    • Environments:  ✓ Production  (and Preview/Development if you want)
    • Save   ( also add  JWT_SECRET  and  GEMINI_API_KEY  here )
    • ⚠  Env vars apply to FUTURE deploys → if already deployed,
         Deployments → ⋯ → Redeploy.

    LOCAL TESTING  (optional)
    ─────────────────────────
    • Put it in  server/.env   (gitignored — won't be pushed):

        MONGO_URI=mongodb+srv://myuser:mypassword@cluster0.xxxxx.mongodb.net/calorie-tracker?retryWrites=true&w=majority

    • ❗ NEVER put the real URI in code, in .env.example, or in a commit.
